# Data and model notes

## Synthetic data generation
The browser creates 500 fictional SKU definitions and 50 fictional distribution-center definitions. For the selected SKU/center pair, it generates 210 days of synthetic demand using a product popularity level, center multiplier, weekday pattern, annual seasonality proxy, promotions, holiday proxy, web-interest proxy, macro proxy, price variation, and random noise.

## Model
The fitted model is a regularized linear regression implemented with gradient descent in JavaScript. Inputs are standardized before fitting. Features include lagged demand (7 and 28 days), rolling recent demand, a simple trend, weekday and month signals, promotion, holiday, web-interest proxy, macro proxy, and price.

## Evaluation
The last 28 history days are held out chronologically for a simple WAPE estimate. WAPE = sum(abs(actual - prediction)) / sum(actual) × 100. Since the underlying data is synthetic and generated by the same demo assumptions, this metric must not be presented as real-world accuracy.
